# java-racingcar-precourse
## 🚘 기능 요구사항 및 구현 목록
### 로직 기능
- 0에서 9까지의 무작위 값을 구한 후 무작위 값이 4 이상일 경우 전진
- 입력 받은 이동 횟수만큼 레이스 진행
- 가장 많이 전진한 자동차를 우승자로 선정
### 입력 기능
- 각 자동자에 이름을 부여할 수 있음 (이름은 다섯글자 이하, 쉽표 기준으로 구분)
- 몇 번의 이동을 할 것인지 입력할 수 있음
### 출력 기능
- 전진할 경우 '-' 출력, 전진하지 않을 경우 출력하지 않음
- 우승자 출력 (한 명 이상일 땐 쉽표로 구분)
### 검증 기능
- 이름이 다섯글자 이하인지
- 이름을 구분할 때 쉽표를 사용했는지
- 이름이 중복되는지
